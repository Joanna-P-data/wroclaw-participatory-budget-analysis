# Wrocław Participatory Budget: Voting Patterns and Data Quality Analysis (2024–2026)

### Project Overview

This project explores voting data from the Wrocław Participatory Budget (Wrocławski Budżet Obywatelski, WBO) for the 2024–2026 editions.
The aim is to examine voting patterns, assess data quality, and investigate how voting outcomes and preferences vary across years and demographic groups.

### Research Questions

- What are the main characteristics of the available voting data?
- Are there data quality issues or unusual patterns that require further investigation?
- How do voting patterns differ across demographic and geographic groups?
- How have voting patterns and project preferences changed between 2024 and 2026?

_The research questions may be refined as the analysis progresses._

### Data Sources

The project uses publicly available WBO voting data published through the Wrocław Open Data Portal.
The availability, structure, and comparability of data across the three editions will be assessed during the project.

### Methodology

The planned analysis includes:

- Exploratory data analysis (EDA)
- Data quality assessment and validation
- Analysis of voting patterns across demographic and geographic groups
- Cross-year comparison, subject to data availability and comparability

Tools: Python, pandas, Jupyter Notebook
